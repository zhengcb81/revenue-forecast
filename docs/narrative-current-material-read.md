# Current narrative material and historical availability

The published `narrative-read-request/1` retains its four required fields.
`as_of_date: null` explicitly reads current source material without asserting
historical availability. Its receipt and source DTO echo null and preserve the
true or unknown publication date. An ISO date still requires a known publication
date at or before the cutoff. Missing fields, malformed dates, mismatched receipts,
wrong source identity, bad artifact bytes and unbound evidence remain refusals.

This is a read-only source context. It does not establish historical forecast
eligibility, accepted investment conclusions, or download/model authorization.
The provider, original language and source locators remain unchanged. No raw paths
or CWP implementation dependencies enter the consumer. Existing dated goldens
and historical counterexamples remain authoritative.

The real three-repository CLI node is coordinated by company-wiki's
`docs/plans/narrative-evidence-pilot-2026-09-26/r3_current_material_read_implementation_2026-10-08.md`.
Its interface test uses real source bytes with explicitly isolated fixture metadata;
live production summary quality and budget/resume/storage acceptance remain R3.
