# RF engineering test ownership

The fast developer push hook runs Ruff and a fixed 12-case smoke. It never runs the full matrix. `python tools/pre_push_gate.py --ci` is the release-grade owner check. Pull requests to main, main publication and explicit workflow dispatch use the same workflow. Both Ubuntu and Windows discover the current `tests/` and `tools/tests/` directories, execute each admitted test once, then compare actual call-phase node IDs to the independently collected inventory. Each job uploads both receipts for the exact checked-out Git revision. Hosted jobs use four pytest-xdist workers and keep tests in the same file together. The local release check can use one or two workers as resources allow. Skips and xfails get no execution credit.

`tools/s6-test-policy.json` declares the same roots and site-independent selection used by both jobs. The Windows-only markers cover genuinely Win32 process/long-path behavior. POSIX-only markers cover detached sessions, symlinks and FIFOs. Each applicable test still runs on one side of the matrix. Use `pytest -m composition` with the prerequisite checkout or executable named by the affected tests for frozen W14/RF, CWP and FF composition, the real CWP narrative producer and three-owner historical checks, Dashboard's read-only historical contract, CodeGraph legacy audits, the real Audit recorder install, and the 4.1.0 full-result hash replay (run the pinned emitting runtime). These are separate, read-only integration obligations. The real-source sample opts into `live` alone, and the production provider must not be contacted by this CI.

The vendored engineering reference is company-wiki P1-00 `b11d45f457a60203bbc7ecb6e598704e4904013b`. Its independent upstream self-tests travel with the reference but are not RF product tests. `tests/contract/test_anti_trick_gates.py` scans the entire current `scripts/` tree against `tools/rf-runtime-baseline.json`, generated at `5a28c0c88df1a8e8fb9b167dbd884eebef7d7894` before changes to product sources. Ratchet existing findings down while changing owner boundaries. The current scanner records only relative source names and rule matches.

For a local Windows test run, set `TEMP` and `TMP` to a short workspace directory before invoking the check. The runner provisions one disposable subtree, uses system-stream pytest capture and starts its Windows child processes without a console. It passes an explicit OS environment allowlist, excludes provider keys and dotenv, and emits only local fixture results. Keep Windows long-path tests enabled.
