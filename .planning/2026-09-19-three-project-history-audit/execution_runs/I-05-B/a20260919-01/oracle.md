## W05B-P1 / positive: Read verified normalized sentinel ALPHA=17

Input: handle with bundle containing a normalized artifact at scratch path
       whose content is b"ALPHA=17\n" (SHA256 = computed from that exact bytes).

Expected:
- `select_artifact_roles` returns `artifact_read = ["normalized"]`, `producer_events` = [] (or whatever DAG says)
- `verify_artifact_reads` called on the selected roles:
  - Reads the file at the artifact's path
  - Computes SHA256 of actual bytes
  - Compares with declared content_sha256
  - Returns `verified_read_events` with: role="normalized", bytes_read=9 (len of b"ALPHA=17\n"),
    content_sha256 matches actual, source_sha256 matches bundle source
  - `failed_read_events` = []
- `artifact_read_events` in the receipt has the verified event (not just the plan)
- `producer_invocations` = [] (no producers actually ran)

## W05B-N2 / negative: Replace artifact between select and read (BETA=29)

Input: After selection, the artifact file is replaced with b"BETA=29\n"
       (different content, different SHA256).

Expected:
- `verify_artifact_reads` detects hash mismatch
- Returns a failed_read_event with reason="content_sha256_mismatch"
- The old hash's success event is NOT paired with new bytes
- The consumer is NOT served stale/wrong content

## W05B-N3 / negative: denied root / placeholder / out-of-bounds / missing

Input: artifact path is outside allowed roots, or is a placeholder, or does not exist.

Expected:
- Refused at the read gate, not silently passed
- Returns failed_read_event with appropriate reason:
  - "artifact_path_outside_allowed_root" for out-of-bounds
  - "artifact_file_missing" for nonexistent path
  - "placeholder_not_hydrated" for cloud placeholders
- No hydration, no provider call, no raw canonical_path fallback
