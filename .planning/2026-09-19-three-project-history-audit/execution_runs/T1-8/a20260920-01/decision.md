## 4. P-4：证据确实分得开，而修复前两族都看不见

**这是本卡的实质发现。** 冻结自检里已有**恰好这两条臂**（M13 与 M17 各一对）：

```
M17 MISSING declaration   -> rc = 2   not_judged = ['N02']   mismatch = []       usable = False
M17 DIFFERENT declaration -> rc = 3   not_judged = []        mismatch = ['N02']  usable = True
M13 PRE-FIX declares-nothing-usable -> rc = 0     <- 修复前：完全看不见
M13 PRE-FIX shape-violated          -> rc = 0     <- 修复前：完全看不见
```

⇒ **「声明不可用」已经有 rc=2，从来不是 rc=3。** 而「声明在场但错误」是 rc=3 —— **这是对的，且不得被"统一"成 rc=2**：`rc=3` 的语义是「**判了，且没通过**」，`rc=2` 是「**判不了**」。把在场但错误的声明压到 rc=2，会**抹掉「判不了」与「判了没通过」的区别**。

⇒ **该句要求的「统一到 rc=2」在子情形上没有对象**：唯一的「期望缺失」形态（不可用声明）**本来就是 rc=2**。

**为什么这条更正是「做项目」而不是「挑字眼」**：若照原文把在场但错误的声明也「统一」到 rc=2，则会**主动引入一个缺陷** —— 一个声明被篡改的卡会从「判负」降级成「无裁决」，即**篡改声明从「失败」变成「无法判定」**。**一个把「判负」读成「判不了」的口径，会让篡改比不篡改更容易通过。**
