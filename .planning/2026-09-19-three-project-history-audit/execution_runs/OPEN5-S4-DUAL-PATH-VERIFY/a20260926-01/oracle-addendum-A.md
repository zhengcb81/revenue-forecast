# OPEN5-S4-DUAL-PATH-VERIFY · oracle-addendum-A（**先于任何测量写入**）

> 依 `oracle.md` §0：判据如需修订必须**另建本文件**、不改 `oracle.md`。本文件写入时间 **早于** 本 attempt 任何测量产物（`_work/*`）的 mtime。

## 为什么需要 addendum（不是事后放宽，是事前补洞）

`oracle.md` §4 M1-补 把 origin 文字层的「可读区」定义为 **(i) ASCII 连串且含字母** 或 **(ii) 正常汉字连串**。
执行前自查发现该定义**漏掉一整类**：origin 文字层虽然 CJK 部分 GID 乱码，但**阿拉伯数字、千分位、小数点通常正确映射**（例：origin 第 43 页可读出 `105,200,000` / `103,200,000` / `24.50` / `51.65`）。
对 `OPEN-5`（港股分部/收入/毛利命题）而言，**数字是否两路一致恰恰是最实质的互证面**。若按原定义把这些串完全排除，则 M1 永远不可能暴露数字矛盾 —— 属于**判据漏洞**，必须在跑之前堵上。

## 补充定义（自本文件起生效）

1. **可读区扩展**：ASCII 可打印连串 `[\x20-\x7e]{4,}`，判据由「含字母」放宽为「**含字母或含数字**」；正常汉字连串（`U+4E00–U+9FFF`，长度 ≥2）不变。两者去重后按归一化文本登记首次出现的行/字节区。
2. **`numeric_conflict`（矛盾，计入 `NOT_USABLE` 触发）**：origin 可读区内**某个 ≥4 位的数字串**（含千分位/小数，比较时去掉分隔符）在同页 OCR 归一化文本中**未逐字复现**，**且**该页 OCR 中存在**数字位数相同、数值不同**的数字串 ⇒ 判为两路读数矛盾。
3. **`miss`（覆盖缺口，不计矛盾）**：origin 可读串在 OCR 中未复现，但不满足第 2 条（只是没读到 / OCR 未覆盖该区域）。计入 `reproduced/total` 覆盖率，决定 `CONSISTENT` 与 `PARTIAL` 的分界。
4. **CJK 可读串未复现**：origin 层中属正常汉字（`U+4E00–U+9FFF`）且长度 ≥4 的串，是**同页视觉内容的真值**；未复现 ⇒ 先按第 2 条判是否有同位不同读；若 OCR 该页**完全没有对应区域文本** ⇒ `miss`，若**有文本但读法不同**（如简繁/字形改写导致归一化后不等）⇒ 登记为 `cjk_variant`，**单列不并入 `miss`**，由报告如实说明（不自动升格为矛盾，因为 `ocr_reconstruction` 已知存在简繁/字形误差，S3 oracle §4.4 明令「引用前需人工核字」）。
5. 本 addendum **只补 M1-补 的 span 集合与冲突判定**，不改 `oracle.md` §5 的三选一判据、不改锚词、不改抽样页、不改通过线、不改 fail-closed。
