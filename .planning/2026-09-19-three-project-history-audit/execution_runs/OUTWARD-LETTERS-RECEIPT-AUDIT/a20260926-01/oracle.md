## 一、七项核验判据（逐项给实测值，不采信任何来件转述）

### J1 sha 三方一致
对三份回执各算三条 sha256（全小写 hex，16 位前缀呈报）：
- **R** = `RESPONSES.md` L5/L6/L7 登记 sha
- **L** = 活文件 `execution_runs/T2-SIM-*/a20260922-01/ruling.md` 实算 sha256
- **T** = 转录段 sha：自 `rulings_transcribed_2026-09-22.md` 的 `----- BEGIN ruling body (byte-exact) -----` 与 `----- END ruling body (byte-exact) -----` 之间逐行以 **LF（`\n`）拼接、无尾换行**后取 sha256
**判定口径（按 L15 精确化）**：`R == T` 才算一致；`R == L` 另记一列。任一 `R != T` ⇒ 该项 `不一致`（fail-closed）。
`R != L` 且 L15 已声明者，须**同时**核对声明的活文件 sha/字节与实测是否逐字相符；声明不符 ⇒ `不一致`。

### J2 函件版本时序
- 实测三函 `A/B/C` 与 `README.md`、`_provenance.json`、`RESPONSES.md`、三份 `ruling.md`、转录件的 `mtime`（秒级）与字节数。
- **回执针对「更新后」函件的判据**：函 A 现行字节（11546 B / `cd88bd4cece0…`）须被回执正文**逐字引用**（sha+字节同时出现）。仅当引用成立才判「针对更新后函件」。
- **过期判据**：若函件 mtime > 回执 mtime，须给出**字节级证据**证明函件内容在回执时点已等于现行内容（前缀证明 / 回执内 sha 引用 / `_provenance.json` 记录）；无任何字节级证据 ⇒ 判 `时序存疑`。
- 三份回执的登记时间 = `RESPONSES.md` 行内所记 `2026-09-22`。

### J3 请求项↔回应对照
以 `A_DW06_OPEN-4-5-6.md`（11546 B）正文的**每一条请求**为行（OPEN-4：4a/4b/4c 三件 + §1.2 两复核项 + §4 回执要求；OPEN-5：§2.1 事实确认 + §2.2 四件 + §2.3 候选修订；OPEN-6：§3.1 三问），逐条在三份 ruling 中找**对应裁定**（须给 ruling 文件与行号）。
`有回应` = 该请求被该职权方**明示作答**（选择 + 落点行号）；`无回应` = 全三份无对应作答；`越域` = 由非职权方作答且原文声明不越域。
**总数、有回应数、缺数须逐条列出**；任一请求在三份中全无回应 ⇒ 记入缺口清单（fail-closed，不得以「大体覆盖」放宽）。

### J4 `CONDITIONAL` 条件兑现
逐条列：OPEN-4 `C1–C6`（6 条）· OPEN-5 `C1–C8`（8 条）· OPEN-6 `C1–C8`（8 条）· 边界补充记 7 条（OPEN-5 §7.4-B 记 1–7）。
每条给三值之一：
- `已兑现` —— 须给**载体路径 + 该载体 sha256（16 位前缀）**，且该载体内容确实承载条件所要求的检验物；
- `未兑现` —— 须写**缺什么**（缺载体 / 缺检验物 / 载体存在但条件文本未被满足）；
- `不可由本工位判定` —— 条件属外部方真实回执或 owner 签收才能定者。
`兑现率 = 已兑现 / 总条数`，分母写明（6+8+8+7 = 29）。

### J5 `_provenance.json` 字节指纹

- 时间戳：`created_at_utc` / `date` 字段 vs 函件实测 mtime，逐条给出先后关系；字段为非机器可解析值（如 `18:1x`）须如实记 `不可解析`。

## 二、一致性判据（总判）
`consistency_status = consistent` 当且仅当 **J1 全过 且 J2 无「时序存疑/矛盾」 且 J3 缺项为 0 且 J5 覆盖三函且指纹相符 且 J6 满足**。
否则 = `inconsistent`，并附**差异明细**（逐条：对象 / 登记值 / 实测值 / 差额）。
**J4、J7 不进总判但必须如实呈报**（条件兑现率、声明缺口单列）。

## 三、`blocked` 触发（任一触发即该项判 `blocked`，不给绿）
1. 任一 sha 三方中 `R != T`（L15 口径）。
2. 任一函 A 请求项在三份回执中**零回应**。
3. 函件 mtime 晚于回执 mtime 且**无任何字节级证据**可证内容当时已定。
4. 登记声明的活文件 sha/字节与实测**不符**（L15 的 5cb47676…/52,560 B 亦须相符）。
5. `_provenance.json` 记录的 bytes/sha 与实测不符（且无勘误条目覆盖该差异）。
6. 冻结令后三份 ruling 仍被改写。
7. 某项条件的**唯一可能载体缺席**（既非 owner 签收件、亦非外部方真实回执）⇒ 该条件判 `blocked`，不得以「登记即兑现」放宽。
