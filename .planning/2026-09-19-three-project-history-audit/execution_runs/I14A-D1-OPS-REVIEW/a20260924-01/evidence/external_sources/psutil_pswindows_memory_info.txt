Reading: psutil's Windows `peak_wset` (and its newer alias `peak_rss`) IS
`PROCESS_MEMORY_COUNTERS.PeakWorkingSetSize` — the same counter a private ctypes
`GetProcessMemoryInfo` call would read. Note also that psutil 8.0 documents
breaking API changes; `peak_wset` is already carried in `_deprecated` here.
