## Call counting contract

- `producer_invocations` is an EVENT LOG, not derived from artifact INSERT count
- Each entry: {role, producer_name, call_status, attempt_number, error (if failed)}
- `parser_calls` = count of entries where producer involves parser
- `llm_calls` = count of entries where producer involves LLM
- Failed attempts are included in counts (the bug this card fixes)
