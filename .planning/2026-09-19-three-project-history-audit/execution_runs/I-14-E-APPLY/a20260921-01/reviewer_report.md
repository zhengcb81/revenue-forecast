### 1.2 Ruling: option (ii) — the distinction is legitimate; card is NOT blocked

Reasoning against the letter:

1. **§5's own model of RED is vacuity.** The paragraph defines the node's failure mode first: watchdog never fires → `unresponsive` empty → RED → R3 fails. The closing sentence (「任何 RED ⇒ blocked, 不得报 review_pending 通过」) is an **anti-self-exemption reporting rule**: its stated prohibition is against *reporting a PASS over a RED*, not a re-definition of what R3 proves. Reading 「任何 RED ⇒ blocked」 as irrebuttable would make C7.2's mandated reviewer distinction dead letter — the frozen text would contain a duty that can never change any outcome. Accepting (ii) therefore **applies** the frozen oracle; choosing (i) after seeing REDs would be the harsher formalism, not the safer one (domain: addendum-C read in full; ruling decided on text frozen at 07:31:56Z, before first run 07:55:53Z).
