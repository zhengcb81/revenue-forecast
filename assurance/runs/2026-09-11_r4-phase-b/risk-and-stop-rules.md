# B 阶段风险与停止规则（risk-and-stop-rules）

> 来源：handbook §5「硬停止」、执行计划 §B 的各步骤检查点、阶段 A 实测事实（A01 §1.1 子进程表、H01 风险、D.SAFE 交叉）。
> 目的：把"什么时候必须停下来问人"写死，避免为了跑绿而绕过安全面。

## 1. H01 风险（自动 prune 可达性）与 B 的交叉

| 事实（阶段 A 已核） | 对 B 的含义 |
|---|---|
| 生产 worker 会周期性扫描并处理；`prune-retired-evidence` 是**物理删除**且 **dry-run 默认**（`cli.py` 帮助文本），`recycle` 需确认 token | B **绝不调用**任何 prune/recycle/archive 入口；B 的读取合同不得隐式触发它们 |
| `resolver.py` 的 `.rejections` 路径过滤现为"canonical 候选剔除"（`resolver.py:918-920`） | B02 改为"**标记但不静默屏蔽**"时，必须保证**不会**让被拒路径重新进入"可写/可删"资格——只影响**只读候选**列表 |
| 空归档目录 + 新 retired 行可触发全量删除（旧 H01 断言，未被 WU 覆盖） | B 的隔离副本实验**不得**包含真实 retired 行；如必须含，先用假数据（D0），并单独批准 |
| **结论** | B 阶段对 H01 的姿态是"**不可达证明 + 不触碰**"：不新增可达入口、不改删除路径、隔离实验中不含真实删除对象 |

## 2. D.SAFE 交叉

| D 项 | 与 B 的关系 | B 阶段动作 |
|---|---|---|
| D02（默认关闭自动回收 / 可信 snapshot 后才允许回收） | B 只读 | **不做**；B 的设计不得依赖"回收已完成" |
| D03（集中操作策略：读域可复用、外发按 privacy/review、写/删除精确对象） | B06/B07 的资格标签与之对齐 | 设计对齐，**不实施**策略变更 |
| D04（独立 Ops 核 D01–D03 并签 D.SAFE） | 不在 B 范围 | **不做** |
| O03「位置变化不能洗掉安全拒绝」 | **与 B04/B02 直接交叉** | B02/B04 的候选选择**必须在安全拒绝之后**，即：被安全策略拒绝的 source 不因"换个 root 就能读到"而放行 —— 设计已写死（资格段第 1/2 段在排序之前，且拒绝不因位置改变而消失） |

## 3. 硬停止清单（本 run 与后续 B 实施一体适用）

1. **越界写**：写到批准文件清单之外、或写到 `company-wiki/.source_catalog/**`、`raw/**`、`artifacts/**` → 立即停止并核对实际状态。
2. **未经批准的外发**：任何网络请求（含 LLM、provider、下载）→ 停（B 阶段设计上不需要网络）。
3. **未知费用/未知结果**：若出现"发出了但不知道结果"的动作 → 先对账，不重试。
4. **bad source/hash**：`content_sha256` 不符 → 显式失败，不回落另一份。
5. **真实 source 被 mock 替换**：B 的 R1 层必须用真实字节；mock 只允许出现在 D0 层并**明确标注**。
6. **必需测试 skip / rc0 但无输出**：不计通过（矩阵与 handbook §5）。
7. **基线漂移**：三仓 HEAD/配置/schema 与冻结值不一致 → 重做受影响部分的基线，不覆盖他人改动。
8. **超时无法取消 / 句柄无法关闭**：B03 的句柄生命周期若不能保证关闭 → 停止该实现方向，回到受控快照方案。
9. **归档/恢复集合不一致**：不在 B 范围；一旦发现涉及删除/恢复的动作被触发 → 停。
10. **隔离不足**：任何"必须在生产 catalog 上验证"的诱惑 → 停（G8）。

## 4. 已知的"看起来能跑通但不算通过"陷阱

| 陷阱 | 为什么不算 | 对策 |
|---|---|---|
| 用人工构造的 catalog 行"证明"读取链正确 | 不能证明真实 parser/索引行为（B08 明文禁止） | D0 只作机制定位；R1 用真实字节 |
| `--help`/`--dry-run` 跑通就宣称行为正确 | 解析期无副作用 ≠ 行为无副作用（A01 F-A01-7） | 行为验证必须真跑 + 独立观察 |
| preview 读到内容就宣称"财报可信" | preview ≠ verified_input（B06） | 资格标签分离 |
| 同 hash 副本很多就宣称"位置透明已达成" | 位置透明要求**引用不因位置改变**（B04/B07），不只是"能读到" | L03/L07 的引用不变验收 |
| 把 `priority` 排序结果当"真伪" | B05 明文禁止 | provenance + 冲突保留 |
