# B08 —— **机制层**实施计划（G8 第①级，owner 2026-09-13 已批）

> **授权边界**：owner 裁定第 1 条批准 G8 **两级**做法；本计划只做**第①级 = 机制层**——在**非生产路径**建一个小 catalog 做隔离环境。**第②级（在隔离根下只读引用真实文件）未获批准**，本计划不涉及；**任何**对生产 catalog 的写入/复制/移动都不在本计划的授权内。
> B08 的验收按 [task_plan.md](../task_plan.md) B08 行：在隔离环境重跑 **L01–L12**（+ 必要旧 C01–C10）并由**独立**的文件/OS 观察证明本地零副作用。本计划先建**可重跑的环境与观察装置**，真实字节那一半留给第②级。

## 1. 为什么机制层就够开工（先例）

- wiki 既有测试**已经**用 `tmp_path` 造小 catalog（B.DR 独立复核过该技术前提）⇒ 机制层不需要 50 GB 拷贝，也不触碰生产库。
- phase A 的 A06-D0 基线（787 unit + 1748 contract passed / 7 skipped）提供了**可对照的行为基线**：机制层要能复现同一条命令、同一批用例在同一隔离根上的结果。

## 2. 交付物（第①级）

1. **隔离根构造器**（脚本，写在 run 目录 `evidence/` 下、**只读**对待产品代码）：
   - 在 `%TEMP%`（或 owner 指定的**非生产**路径）下建一个**最小 catalog**：只含重跑 L01–L12 所需的表结构与合成行；构造过程**全部**落在该目录内。
   - 幂等：重复运行得到同一形状（可重跑）；构造完打印**根路径 + 文件清单 + 每个文件的大小/哈希**（作为"隔离根"的锚）。
2. **观察装置（两侧证据）**：
   - **前**：构造前对**本机生产库路径**只取元数据（大小/mtime，主库与 `-wal`/`-shm`）——按 G5 记录的协议，**先**做一段平坦的 `-shm` 基线轮询，否则 `-shm` 移动不可用；
   - **后**：重跑 L01–L12 之后再取一次，并输出**判定**（主库变 ⇒ 写入；`-wal` > 0 ⇒ 写入；两者皆无 ⇒ 无写入证据）。
   - **同时**记录隔离根内文件清单的变化 ⇒ "副作用只发生在隔离根内"这一半由**文件系统**证明，不靠自述。
3. **L01–L12 重跑清单**：逐条给出"用哪个用例/命令在隔离根上重跑"，并标注**当前可跑/需第②级（真实字节）**；不可跑的**不假装**跑了。
4. **与 A06-D0 的对照**：同命令同用例在隔离根上的结果 vs A06-D0 记录，差异逐条解释。

## 3. 明确不做（第①级）

- 不复制、不移动、不修改生产 catalog 或任何生产语料。
- 不引用真实文件字节（那是第②级）。
- 不改产品代码；若重跑暴露产品缺陷 ⇒ **登记**并单独走处置，不夹带修。

## 4. 验收（可证伪）

- [ ] 隔离根可在**非生产路径**一次命令重建，并给出根锚（清单+哈希）。
- [ ] L01–L12 中**能跑的**在隔离根上跑完，结果与 A06-D0 对照差异逐条解释；不能跑的逐条标注"需第②级"。
- [ ] **零副作用证据**：生产库主库 size/mtime 与本级开始时一致、`-wal` 仍 0 字节；且给出基线轮询的**平坦性**结论（不平坦则明确写"不可归因"）。
- [ ] 观察装置**可复跑**（脚本入库 + 用法写明）。
- [ ] 独立复审一轮（按 §11），处置表入库。

## 5. 风险 / 未知

- **合成 catalog 的代表性**：L01–L12 里有多少条**必须**真实字节才能判定？本计划第 3 项要**如实列出**，不允许把"机制层通过"说成"B08 通过"。
- **本机 `-shm` 饱和**（G5 观测）：观察装置必须自带基线轮询，且当基线非平坦时**明确拒绝**给出归因结论。
- 隔离根若落在被同步的目录（Dropbox/OneDrive）会产生额外副作用 ⇒ 构造器要**检查并拒绝**同步目录路径（写在脚本里）。
